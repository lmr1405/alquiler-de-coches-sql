# Base de datos de Alquiler de coches

## **Trabajo grupal para la asignatura de base de datos** 

Consta de 4 archivos:
- **schema.sql** contiene la estructura para generar las tablas
- **data.sql** contiene la introducción de los primeros datos insertados para poder realizar las distintas pruebas
- **queries.sql** contiene las distintas consultas solicitadas
- **relax.txt** contiene consultas en álgebra relacional, un lenguaje formal basado en operadores matemáticos utilizado para consultar y manipular datos en bases de datos relacionales.
